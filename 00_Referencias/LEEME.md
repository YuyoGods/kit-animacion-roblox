# Aquí van los videos de referencia

Videos de otros creadores cuyo estilo de cámara quieres copiar (cortes, zooms, temblor, transiciones).

Pásale el video a Claude y pídele: **"Analiza esta referencia del creador X"**. Corre:
```
py -X utf8 04_Herramientas/analisis/analizar_referencia.py "video.mp4" --creador X
```
y deja aquí `X/ref_##/` con hojas de contacto, gráfica, transcripción y ficha, más `X/ficha_estilo.md` (resumen del creador). Guía: `docs/07_ANALISIS_REFERENCIAS.md`.

Esta carpeta es personal: git no la sube.
