# Escenarios

- `Pueblo/` — mapa por defecto del kit (`Pueblo_set.blend` + `scripts/` que lo construyen). **Se actualiza con el kit: no lo modifiques directamente.**
- ¿Quieres cambiar el pueblo o hacer otro mapa? Cópialo a una carpeta nueva (ej. `Mi_Pueblo/`) o crea una (ej. `Bosque/`). Esas carpetas son tuyas: git no las sube ni las toca al actualizar.

Mapa, coordenadas y alturas del Pueblo: `docs/04_ESCENARIOS.md`.
